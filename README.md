\# AdoptoCare – Pet Adoption \& Care Ecosystem



AdoptoCare is a web-based platform designed to simplify pet adoption and pet care management by connecting pet lovers, shelter managers, veterinarians, and administrators.



\## Technologies Used



\*\*Backend\*\*

\- Java

\- Spring Boot

\- Spring Security

\- Hibernate / JPA

\- REST APIs

\- JWT Authentication



\*\*Frontend\*\*

\- React.js

\- JavaScript

\- HTML5

\- CSS3

\- Bootstrap



\*\*Database \& Tools\*\*

\- MySQL

\- Maven

\- Git \& GitHub

\- Postman

\## Getting Started



\### Prerequisites



\- Java JDK

\- Maven

\- Node.js and npm

\- MySQL



\### Backend Setup



1\. Navigate to the backend folder.

2\. Configure database and environment variables.

3\. Run the Spring Boot application.



```bash

cd backend

mvn spring-boot:run

```



\### Frontend Setup



1\. Navigate to the frontend folder.

2\. Install dependencies.

3\. Start the development server.



```bash

cd frontend

npm install

npm run dev

```



\## Environment Configuration



Configure these environment variables before running the backend:



\- `DB\_USERNAME`

\- `DB\_PASSWORD`

\- `JWT\_SECRET`

\- `MAIL\_USERNAME`

\- `MAIL\_PASSWORD`



Do not commit passwords, API keys, or other sensitive credentials.
